## 1. Погружение (30 мин) — аудит smlogik.ru

**Продукт:** премиальная алюминиевая садовая мебель SmartLogic, доставка по РФ, водоотталкивающие чехлы, заводское производство.

**Целевое действие на сайте:** заявка на видеообзор / консультацию и покупка комплекта.

**CRO-проблемы текущего сайта:**

1. **Размытый бренд** — SmartLogic / smlogik звучит как IT, не как premium outdoor.
2. **Много равнозначных CTA** — каталог, корзина, оплата, видеообзор конкурируют друг с другом.
3. **Лид-форма не в фокусе** — сильный оффер «видеообзор + консультация» спрятан ниже по странице.
4. **Длинный путь до решения** — много текста и блоков до понятного «что делать дальше».
5. **Перегруз первого экрана** — несколько выгод без одного главного сообщения.

**Вывод:** цель редизайна — не «красивее», а **↑ конверсия в заявку** через один понятный сценарий.

## 2. Конкуренты (30 мин)

Просмотрела лендинги премиальной садовой мебели и outdoor-категории (РФ).

**Паттерны у сильных:**

- Hero = одна выгода + одна кнопка.
- Социальное доказательство (отзывы / фото) в первых 2–3 экранах.
- Лид-магнит («подбор», «замер», «каталог в WhatsApp») вместо сразу корзины.
- Mobile: sticky CTA.

**Применила:** один primary CTA, отзывы до формы, sticky-кнопка на mobile.

## 3. Новая концепция бренда (30 мин)

| | Было | Стало |
|---|------|--------|
| Название | SmartLogic | **Still Patio** |
| Ассоциация | IT / логика | Спокойная терраса, premium outdoor |
| Тон | Каталог + магазин | Подбор комплекта + видеообзор |

**Design system для AI и вёрстки:**

- Шрифт: Manrope  
- Фон: `#FAF9F6`, текст `#1A1A18`  
- Акцент: `#2D4A3E` (глубокий зелёный), CTA `#C4A574` (тёплый sand)  
- Стиль: много воздуха, крупное фото террасы, минимум шума  
- Mobile-first, один CTA

## 4. AI-процесс (30 + 30 мин)

**Инструменты:** ChatGPT / Cursor (Claude).

**Промпт (суть):** landing для premium aluminum garden furniture, цель — lead form, RU, структура hero → 3 benefits → social proof → form, один CTA, HTML/CSS single file, CRO best practices.

**Мой вклад после AI:**

- Сократила тексты под оффер «подбор + видеообзор».
- Добавила блок «было / стало» с CRO-логикой.
- Настроила sticky CTA, success-state формы, noindex.
- QA: mobile 390px, контраст кнопок, один сценарий до заявки.

---

## 5. CRO-решения в прототипе

1. **Один главный CTA** — «Получить подбор и видеообзор» (hero + header + sticky).
2. **Hero** — эмоция террасы + 3 trust-бейджа, без корзины на первом экране.
3. **Отзывы** до формы — снижение риска перед заявкой.
4. **Форма** — имя + телефон, минимум полей.
5. **Compare-блок** — явно показывает, зачем менять концепцию (для ревьюера).
