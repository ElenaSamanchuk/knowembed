1. Sign up

  1. Open Start free → create account (email + password).
  2. Dashboard shows seeded bot Store Assistant.

2. Index knowledge

  1. Open Store Assistant workspace.
  2. If chat is locked, click Re-index demo FAQ.
  3. Confirm acme-faq.md appears under Knowledge docs.

3. Test in-app chat

  1. Ask: How long is shipping?
  2. Expected: answer about 3–5 business days (Groq + FAQ context).
  3. Ask: What is the return policy?

4. Publish & embed

  1. Click Publish bot.
  2. Open embed demo page.
  3. Use widget bottom-right — same answers as in-app.

5. Pricing

  1. Pricing → Upgrade with Stripe test (mock checkout).
  2. Pro removes widget branding and raises limits.

Stack

Supabase (auth, Postgres, Edge Functions) · Groq Llama 3.3 · React app · Shadow DOM widget
